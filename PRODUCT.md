# NaiguaStore

Spanish-language PC hardware catalog for Venezuelan customers. The user supplied the NaiguaStore emblem, a prior screenshot and the WhatsApp destination 584146380868. The target GitHub repository was empty at implementation start.

Primary task: find a component, read its specifications and prepare a complete WhatsApp quote request. This is a static GitHub Pages site: no payments, inventory reservation or server-side orders.

The four initial models and reference prices come from the user's screenshot. They are not current verified offers. Stock, exact GPU assembler, RAM SKU, delivery coverage, payment availability, guarantee duration and tax handling remain unconfirmed. The storefront must say so in human language. Never render an InStock Offer, fake reviews, order numbers, delivery promises or payment details as fact.

Customers can search, filter and order the small catalog, use dedicated category/product URLs, read compatibility guidance and build a persistent local cart. Contact details on the quote form are optional. WhatsApp opening is not message delivery or purchase confirmation.

No analytics property or Search Console credentials have been supplied. No tracking is installed. Search intent research is qualitative; no search-volume estimates were obtained.
